# Plan d'implémentation — Sous-projet 9 : Site vitrine kaloe.fr

Spec : `docs/superpowers/specs/2026-10-14-site-design.md` (référencée ci-dessous par « spec §x »).
Branche : `main` (travail direct, à la demande de l'utilisateur).

## Conventions

- **TDD** dans le Worker (`worker/test/*.test.ts`, Vitest dans workerd, GitHub simulé par `mockFetch`) : test → échec → implémentation → `npm test` + `npm run typecheck` verts → commit.
- Le rendu se vérifie à l'œil avec `npm run dev` dans `worker/` (captures à ~1280 px et ~375 px, clair et sombre).
- **Un commit par tâche**, message court en anglais à l'impératif minuscule.
- **Attention : un push sur `main` qui touche `worker/` redéploie `kaloe.fr`** (`.github/workflows/worker.yml`, si le jeton Cloudflare est configuré). Ne pas pousser avant la tâche 9 ; commits locaux seulement.
- Les modifications non commitées du tutoriel (son, `sfx.py`, `voice.py`…) ne sont pas incluses dans les commits de ce plan.
- Points d'arrêt marqués : l'utilisateur fournit ou valide quelque chose avant de continuer.
- Cocher les cases au fur et à mesure.
