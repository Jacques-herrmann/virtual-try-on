Branche : `main` (travail direct, à la demande de l'utilisateur).

## Conventions

- **TDD** pour `core.paths`, `updates` et `desktop` : écrire le test → le voir échouer → implémenter → `pytest` + `ruff check` verts → commit.
- Front : Vitest pour les composants partagés ; le rendu se vérifie à l'œil dans `vto-app --dev` + `npm run dev`, avec des captures.
- **Un commit par tâche**, message court en anglais à l'impératif minuscule (`rename data folder to wearo`).
- Aucun `data-test` supprimé ni renommé ; aucun store ni appel d'API modifié par la refonte.
- Cocher les cases au fur et à mesure.
