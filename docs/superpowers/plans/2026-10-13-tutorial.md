# Plan d'implémentation — Sous-projet 7 : Tutoriel de première ouverture

Spec : `docs/superpowers/specs/2026-10-13-tutorial-design.md` (référencée ci-dessous par « spec §x »).
Branche : `main` (travail direct, à la demande de l'utilisateur).

## Conventions

- **TDD** pour le backend (`config`, route des réglages, outil de tournage) et pour `composables/tour.ts` : test → échec → implémentation → `pytest` / `npm test` + `ruff check` verts → commit.
- Le rendu (bulles, lecteur) se vérifie à l'œil dans `vto-app --dev` + `npm run dev`, avec des captures.
- **Un commit par tâche**, message court en anglais à l'impératif minuscule.
- Aucun `data-test` supprimé ni renommé ; les `data-tour` s'ajoutent à côté.
- Points d'arrêt marqués : l'utilisateur fournit ou valide quelque chose avant de continuer.
- Cocher les cases au fur et à mesure.
