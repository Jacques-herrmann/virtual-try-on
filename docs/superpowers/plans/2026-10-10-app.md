# Plan d'implémentation — Sous-projet 2 : App

Spec : `docs/superpowers/specs/2026-10-10-app-design.md` (référencée ci-dessous par « spec §x »).
Branche : `feat/app` (créée depuis `spec/app`).

## Conventions

- **TDD** pour le cœur et l'API : écrire le test → le voir échouer → implémenter → `pytest` + `ruff check` verts → commit.
- Front : Vitest pour `api.ts` et la logique d'état ; les vues sont vérifiées à la main dans `vto-app --dev` + `npm run dev`.
- **Un commit par tâche** (ou sous-étape notable), message court en anglais à l'impératif minuscule (`add generation queue`).
- Tests Python : fixture `data_dir` partout, `FakeClient` injecté, aucun appel réseau hors `-m live`, aucun `sleep` réel.
- Textes visibles par le client : français, tutoiement, sans jargon.
- Cocher les cases au fur et à mesure.
